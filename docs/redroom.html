Comment jouer

  1. Lis l'énoncé d'une épreuve sur la page Énoncés & indices.
  2. Télécharge le fichier et cherche le message caché dedans (stéganographie).
  3. Soumets le flag trouvé dans la carte de l'épreuve, plus bas. Format obligatoire : B1{...}
  4. Chaque vrai flag débloque une lettre et un enregistrement dans les Archives.
  5. Avec les 5 vrais flags, accuse le coupable.

Bloqué ? Chaque épreuve a 2 indices sur la page des énoncés.
Tu trouves B1{X01.EXE ta bien eu ses un fake} ? C'est un faux flag : il t'a eu, continue de chercher.
