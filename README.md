# Atelier du Pôle Nord · Intranet

Intranet interne des employés de l'Atelier du Pôle Nord. Accès réservé aux employés actifs.

## Lancer en local

Double-cliquer sur `deployer.bat`, ou :

```
docker compose up -d --build
```

Puis ouvrir http://localhost:8080

> Les caméras de l'atelier sont actuellement en maintenance.
